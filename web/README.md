# TechStore Web (React + Vite)

Frontend của TechStore. Hướng dẫn cài đặt và chạy nằm ở [README.md ở thư mục gốc](../README.md).

| Lệnh | Tác dụng |
| --- | --- |
| `npm run dev` | Chạy web ở http://localhost:5173, request `/api` được chuyển sang API ở cổng 3000 |
| `npm run build` | Kiểm tra kiểu TypeScript và build ra `dist/` |
| `npm run lint` | Kiểm tra code bằng oxlint |
