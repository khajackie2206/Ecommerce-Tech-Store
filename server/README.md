# TechStore API (NestJS)

Backend của TechStore. Hướng dẫn cài đặt và chạy nằm ở [README.md ở thư mục gốc](../README.md).

| Lệnh | Tác dụng |
| --- | --- |
| `npm run start:dev` | Chạy API ở http://localhost:3000/api/v1, tự khởi động lại khi sửa code |
| `npm test` | Unit test (không cần SQL Server) |
| `npm run test:e2e` | E2E test (cần SQL Server đang chạy) |
| `npm run lint` | Kiểm tra code bằng oxlint |
| `npm run build` | Biên dịch ra `dist/` |
